# Edge-template-NextJS

## Getting Started

Follow these steps to start the development server:

### 1. Install Dependencies

Using **npm**:

```bash
npm install
```
Using **yarn**:

```bash
yarn install
```

### 2. Run the Development Server

Using **npm**:

```bash
npm run dev
```
Using **yarn**:

```bash
yarn dev
```

### 3.  Open in Browser

http://localhost:3000
